# DoaFácil - APAE Bananal SP
Sistema interno de gestão de doações com menu retrátil, cadastro de doadores com validação de CPF e opção de doador anônimo.

## Funcionalidades
- Menu lateral retrátil responsivo
- Cadastro de doadores com CPF validado
- Doador anônimo (LGPD)
- Registro de doações por usuário interno
- Dashboard e exportação CSV

## Tecnologias
HTML5, CSS3, JavaScript puro + LocalStorage
